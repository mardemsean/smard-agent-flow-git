## SMard Agent Flow 0.6.2 — the first release

SMard Agent Flow is an add-on (a plugin) for coding agents. It was created in Claude Code and today operates in harnesses of twelve vendors. It helps you take an idea from the first discomfort ("something here is wrong") to working software, and it keeps the choices in your hands while the agent does the typing.

### Install on Windows

The installers of this release set it up for **Claude Code**, which must already be installed.

1. Download **`SMardAgentFlow-Setup-0.6.2.exe`** from *Assets*, at the bottom of this page.
2. Double-click it and follow the screens. It does not ask for an administrator password.
3. Open a **new** Claude Code session and type **`/smard-agent-flow`**.

That is all. To remove it later, open *Installed apps* in the Windows Settings and uninstall *SMard Agent Flow*.

> [!NOTE]
> Windows can show a blue box that says "Windows protected your PC". It appears because the installer does not have a paid digital signature yet. Choose **More info**, then **Run anyway**.

### Other ways to install

| You prefer | Do this |
| --- | --- |
| **Claude Code itself** | Type `/plugin marketplace add mardemsean/smard-agent-flow-git`, then `/plugin install smard-agent-flow@smard-agent-flow-marketplace` |
| **Node.js** | Run `npx github:mardemsean/smard-agent-flow-git` in a terminal. Or download `smard-agent-flow-0.6.2.tgz` and run `npm install -g .\smard-agent-flow-0.6.2.tgz`, then `smard-agent-flow` |
| **A ZIP, no installer** | Download `smard-agent-flow-0.6.2-windows.zip`, extract it, double-click `Install.cmd` |
| **winget** | Not available yet. The manifest is ready (`winget-manifest-0.6.2.zip`, package `SMardLabs.SMardAgentFlow`); `winget install` will work after the package enters the winget community repository |

Every way puts the same files in the same place: your Claude Code settings folder (`.claude` in your user folder). Nothing else on the computer changes.

### What you get

- The command **`/smard-agent-flow`**, the door to the method.
- Twelve skills for the steps of the work: explore an idea, clarify it, write what you intend, decide the architecture, plan the tasks, implement, check, deliver, hand a session over.
- The documents of the method, inside the plugin, so that it works without anything else.

It installs no background programs, no hooks and no MCP servers.

### Honest about state

The method is still in elaboration. Three things that its documents describe are **not built yet**: the hook that saves a session before compaction, the automatic recovery of a session, and the integration with Spec Kit.

### Check your download (optional)

`SHA256SUMS.txt` lists the fingerprint of each file. In PowerShell: `Get-FileHash .\SMardAgentFlow-Setup-0.6.2.exe`, and compare.
