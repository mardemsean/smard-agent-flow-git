SMard Agent Flow {{VERSION}} - from discomfort to production
============================================================

SMard Agent Flow is a plugin (an add-on) for Claude Code.
You need Claude Code already installed on this computer.

INSTALL
  1. Extract this ZIP to a folder (right-click the ZIP, "Extract All").
  2. Double-click  Install.cmd
  3. Open a NEW Claude Code session and type:  /smard-agent-flow

REMOVE
  Double-click  Uninstall.cmd
  The files go to the Recycle Bin.

WHAT IT CHANGES
  It copies files into your Claude Code settings folder (.claude in your
  user folder) and nothing else. It does not need an administrator password.
    skills\smard-agent-flow\         the plugin
    commands\smard-agent-flow.md     the /smard-agent-flow command

IF WINDOWS SHOWS A WARNING
  Windows can warn about files that come from the internet. The installer
  in this ZIP is a text script; you can open files\plugin\install.ps1 in
  Notepad and read what it does.
