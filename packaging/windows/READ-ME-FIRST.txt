SMard Agent Flow {{VERSION}} - from discomfort to production
============================================================

SMard Agent Flow is a workflow plugin (an add-on) for coding agents. It was
created in Claude Code and today operates in harnesses of twelve vendors.
This package installs it into the harnesses YOU choose.

WHAT IS IN THIS ZIP
  Install-All.cmd            installs into every harness detected on this
                             computer (recommended)
  Install-<harness>.cmd      one installer per harness (Claude Code, Kimi
                             Code, Junie, IBM Bob, Hermes, Grok, Cursor,
                             Windsurf, Codex, Antigravity, Kilo, OpenCode,
                             Copilot)
  Uninstall-All.cmd          removes it from every harness it was installed in
  Install.cmd / Uninstall.cmd  the classic Claude Code pair
  files\                     the package the installers copy from
  LICENSE.txt                MIT

INSTALL
  1. Extract this ZIP to a folder (right-click the ZIP, "Extract All").
  2. Double-click  Install-All.cmd
     (or the Install-<harness>.cmd of the harness you use).
  3. Open a NEW session of the harness and invoke smard-agent-flow
     (in Claude Code, type:  /smard-agent-flow)

WHAT IT CHANGES
  Only your own settings folders, one skill (or agent file) per harness, and
  nothing else. It never asks for an administrator password. Whatever differs
  from a previous version is backed up next to it with a .bak- date suffix,
  and a folder that is not SMard Agent Flow is never touched.

IF WINDOWS SHOWS A WARNING
  Windows can warn about files that come from the internet. The installers in
  this ZIP are text scripts; you can open files\packaging\install-harness.ps1
  in Notepad and read what it does.
