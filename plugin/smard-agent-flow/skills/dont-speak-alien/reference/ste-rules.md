# STE rules reference (paraphrased)

Source: ASD-STE100 Simplified Technical English, Issue 9 (2025-01-15), Part 1 (Writing rules) only. Paraphrased, not quoted. The Part 2 dictionary is not included. Rule numbers cite the specification.

Tags: [mechanical] = a script can check it without a dictionary. [judgment] = needs a person or a model.

## Section 1 - Words

- RULE 1.1 — Use only dictionary words, technical nouns, or technical verbs. [judgment]
- RULE 1.2 — Use each approved word only as the part of speech it is approved for. [judgment]
- RULE 1.3 — Use each approved word only with its one approved meaning. [judgment]
- RULE 1.4 — Use only the verb and adjective forms the dictionary lists. [judgment]
- RULE 1.5 — Treat a word as a technical noun only if it fits a named subject category (parts, materials, tools, units, colors, software terms, and so on). [judgment]
- RULE 1.6 — Use an unapproved word only when it is a technical noun or part of one. [judgment]
- RULE 1.7 — Never turn a technical noun into a verb; rephrase ("Apply oil", not "Oil it"). [judgment]
- RULE 1.8 — Use the technical noun your company or field already approves. [judgment]
- RULE 1.9 — When you must invent a technical noun, keep it short (three words at most) and clear. [judgment]
- RULE 1.10 — Avoid regional words, slang, and jargon as technical nouns. [judgment]
- RULE 1.11 — Name one item with one technical noun throughout. [judgment]
- RULE 1.12 — Use a technical verb only if it fits a named category (manufacturing, computer actions, field-specific actions, legal). Prefer an approved verb when one is exact. [judgment]
- RULE 1.13 — Never use a technical verb as a noun; its past participle may be an adjective. [judgment]
- RULE 1.14 — Use American spelling unless an official directive says otherwise; keep quoted text as is. [judgment]

## Section 2 - Multi-word nouns

- RULE 2.1 — Keep a noun group to three words or fewer; split longer ones with prepositions or verbs. [mechanical]
- RULE 2.2 — For an official term longer than three words, write it in full once. Then use a shorter form, an approved abbreviation, or hyphens that join words into one unit. [judgment]

## Section 3 - Verbs

- RULE 3.1 — Use only the verb forms the dictionary lists. [judgment]
- RULE 3.2 — Allowed forms: infinitive, imperative, simple present, simple past, simple future, past participle as adjective. [mechanical]
- RULE 3.2a — No present perfect, past perfect, progressive, or other compound tenses. [mechanical]
- RULE 3.3 — Use a past participle only as an adjective showing condition: before a noun, or after be, become, or stay. [judgment]
- RULE 3.4 — Do not build compound verbs with auxiliaries (have + participle, is to be + participle, can be + participle). [mechanical]
- RULE 3.5 — Use the -ing form only as a technical noun or as a modifier inside one (for example a heading or "sanding machine"). [mechanical]
- RULE 3.6 — Use the active voice. In descriptive text, the passive is allowed only when the doer is unknown. [mechanical]
- RULE 3.6a — To fix a passive: name the doer as subject, turn an infinitive into the verb, use the imperative in procedures, or use "you" or "we". [judgment]
- RULE 3.7 — Express an action with a verb, not a noun phrase ("The gauge shows 5", not "gives an indication of 5"). [judgment]

## Section 4 - Sentences

- RULE 4.1 — Write short, clear sentences with one topic each; state concrete facts, not abstract claims. [judgment]
- RULE 4.2 — Never drop articles, subjects, verbs, or nouns to save words. [judgment]
- RULE 4.2a — Do not use contractions ("do not", not "don't"). [mechanical]
- RULE 4.3 — Put long enumerations or steps in a vertical list. [judgment]
- RULE 4.3a — Vertical list layout: end the lead-in with a colon, mark each item with a dash, bullet, letter, or number, start each item with a capital letter. [mechanical]
- RULE 4.3b — End an item with a period only if it is a full sentence; no commas or semicolons at item ends; end the last item with a period. [mechanical]
- RULE 4.3c — Keep items on one level, make each fit the lead-in, and do not mix procedure and description in one list. [judgment]
- RULE 4.3d — In safety lists, put "DO NOT" inside each item, not in the lead-in. [mechanical]
- RULE 4.4 — Link related sentences with connecting words or phrases (and, but, then, thus, as a result). [judgment]
- RULE 4.5 — Put an article or "this/these" before a noun when it applies; skip articles for general or abstract statements. [judgment]
- RULE 4.5a — Do not put "the" before an identifier such as a part number. [mechanical]

## Section 5 - Procedural writing

- RULE 5.1 — Keep each procedural sentence to 20 words or fewer, safety text included. [mechanical]
- RULE 5.2 — Give one instruction per sentence, unless two actions happen at the same time. [mechanical]
- RULE 5.2a — A step may hold two sentences when actions are simultaneous or a result follows at once. [judgment]
- RULE 5.3 — Write instructions as imperatives; avoid "must" before an imperative unless safety or a key condition needs it. [mechanical]
- RULE 5.4 — Put a needed condition first, then a comma, then the command ("If it leaks, stop"). [mechanical]
- RULE 5.5 — Notes give information only: no commands, requirements, or limits. [mechanical]
- RULE 5.5a — A note sentence has 25 words or fewer. [mechanical]
- RULE 5.5b — Limits and results go in the step itself; risk of harm goes in a warning or caution. [judgment]
- RULE 5.5c — Test: the procedure must work with all notes removed. [judgment]

## Section 6 - Descriptive writing

- RULE 6.1 — Release information gradually, one subject per sentence; no imperatives. [judgment]
- RULE 6.2 — Repeat key words and key phrases across sentences to build a logical chain. [judgment]
- RULE 6.3 — Keep each descriptive sentence to 25 words or fewer. [mechanical]
- RULE 6.4 — Group related sentences in paragraphs that open with a topic sentence. [judgment]
- RULE 6.5 — One topic per paragraph. [judgment]
- RULE 6.6 — At most six sentences per paragraph. [mechanical]

## Section 7 - Safety instructions

- RULE 7.1 — Label each safety instruction by risk level: warning for injury or death, caution for equipment damage; use warning if both. [judgment]
- RULE 7.2 — Open with a clear command or a condition the reader must know first. [judgment]
- RULE 7.3 — Add a short explanation of the risk or result. [judgment]

## Section 8 - Punctuation and word count

- RULE 8.1 — Standard punctuation is fine, except the semicolon; use two sentences instead. [mechanical]
- RULE 8.2 — Join directly related words with hyphens (compound adjectives, two-word numbers, letter-noun shapes). [judgment]
- RULE 8.3 — Parentheses are allowed for references, item identifiers, step numbers, abbreviations, singular-or-plural, brief explanation, or an alternative. [judgment]
- RULE 8.4 — In a vertical list, the colon ends the first sentence; each item counts as its own sentence. [mechanical]
- RULE 8.5 — Parenthesized text counts as one word in its host sentence, and counts separately as its own sentence. [mechanical]
- RULE 8.6 — Count as one word each: a number, a number with its unit, an abbreviation, an alphanumeric identifier, quoted text, a title or label, a proper noun of a person, group, organization, or country. [mechanical]
- RULE 8.7 — A hyphenated compound counts as one word. [mechanical]

## Section 9 - Writing practices

- RULE 9.1 — If a one-for-one word swap fails or changes meaning, rebuild the sentence. [judgment]
- RULE 9.2 — Check the approved meaning and part of speech before using a word. [judgment]
- RULE 9.3 — Do not combine words into phrasal verbs ("extinguish", not "put out"). [judgment]
- RULE 9.4 — Use the same wording each time the same kind of step recurs. [judgment]
- RULE GR-1 — Keep the conjunction "that" after verbs like "make sure". [mechanical]
- RULE GR-2 — Recheck "with" for several readings; restructure if unclear. [judgment]
- RULE GR-3 — Replace a pronoun with its noun when the referent is unclear; use only approved pronouns, never "he" or "she". [mechanical]
- RULE GR-4 — Make clear what "this" points to; add the noun if not. [judgment]
- RULE GR-5 — Beware false friends from your native language. [judgment]
- RULE GR-6 — Avoid Latin abbreviations (e.g., i.e., etc.). [mechanical]
- RULE GR-7 — Use gender-neutral wording. [judgment]
- RULE GR-8 — Possessive ('s) is allowed; drop it if unsure. [judgment]
